# 🧺 Food Finder

Swipe through recipes, plan the week's cooking, and get one smart shopping list. The aim is to save money, waste less food and cook tasty meals.

**Open the app:** https://eurotrash3.github.io/Food-Finder-App/

On a phone, open the link in Safari or Chrome and choose **Add to Home Screen** to install it like an app.
